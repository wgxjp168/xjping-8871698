# 我来购ILbuy 场景测试用例

## 概述

| 属性 | 说明 |
|------|------|
| 项目名称 | 我来购ILbuy采购平台 |
| 测试类型 | 业务场景测试（E2E Scenario Test） |

## 场景一：B2B企业采购全流程

### 背景

某制造企业需要批量采购工业零配件，金额较大（50万元），需要增值税专用发票，要求供应商具备相关资质，整个流程需要多级审批。

---

### TC-SCE-001 B2B批量采购完整流程（正常路径）

**参与角色：**
- 企业采购员（buyer@corp.com）
- 企业采购经理（manager@corp.com）
- 供应商A（supplierA@abc.com）
- 供应商B（supplierB@xyz.com）
- 平台管理员

**前置条件：**
- 企业账号已注册并通过审核
- 供应商A、B已入驻且资质齐全
- 审批流程已配置（采购金额>10万需经理审批，>50万需总监审批）

---

**Step 1：采购员创建采购需求**

```
操作：采购员登录后台，填写采购需求
输入：
  - 采购类型：B2B企业采购
  - 品类：工业零配件 > 精密轴承
  - 需求描述：SKF 6210-2Z 深沟球轴承，内径50mm，外径90mm，宽度20mm
  - 数量：500套
  - 预算金额：50万元（含税）
  - 交货期：30天
  - 收货地址：上海市嘉定区某工业园区
  - 发票要求：增值税专用发票（税率13%）
  - 质量要求：附质检报告，符合GB/T276-2013标准
  - 附件：采购规格书.pdf

预期结果：
  √ 需求保存成功，状态：草稿(DRAFT)
  √ 表单验证：所有必填项已填写
  √ 系统提示：预算超过50万，需总监级审批
```

**Step 2：提交审批**

```
操作：采购员点击"提交审批"按钮
预期结果：
  √ 需求状态变更为：待审批(PENDING_APPROVAL)
  √ 采购经理收到审批通知（邮件+站内信）
  √ 审批链显示：采购员→采购经理→采购总监
```

**Step 3：采购经理审批通过**

```
操作：采购经理登录，查看审批列表，点击"同意"
输入：审批意见："同意，预算合理，请加急处理"
预期结果：
  √ 审批记录写入（时间、操作人、意见）
  √ 流程流转到采购总监
  √ 采购总监收到审批通知
```

**Step 4：采购总监审批通过**

```
操作：采购总监审批同意
预期结果：
  √ 需求状态变更为：已审批(APPROVED)
  √ 系统自动触发AI供应商匹配
  √ 采购员收到通知："审批已通过，正在匹配供应商"
```

**Step 5：AI智能匹配供应商**

```
系统自动操作：
  - AI分析需求关键词（轴承/SKF/精密/50mm）
  - 匹配供应商资质库（机械零配件资质）
  - 综合评分：历史成交、评价、响应速度、价格竞争力
  - 排除黑名单供应商

预期结果（5分钟内完成）：
  √ 推荐3-5家匹配供应商（匹配分≥70）
  √ 供应商A（匹配分：95）：历史供应SKF产品，交货准时率98%
  √ 供应商B（匹配分：87）：SKF授权经销商，价格有竞争力
  √ 匹配报告：包含AI分析、价格参考区间、风险提示
```

**Step 6：发起询价**

```
操作：采购员选择供应商A、B发起询价
输入：
  - 报价截止时间：3个工作日
  - 询价备注：请提供SKF原厂产品及质检报告，含税报价

预期结果：
  √ 询价单创建，状态：已发送(SENT)
  √ 供应商A、B各收到询价通知
  √ 询价截止倒计时显示
```

**Step 7：供应商提交报价**

```
供应商A操作：
  - 单价：860元/套
  - 总价：430,000元（含13%增值税）
  - 交货期：20天
  - 最小订量：100套
  - 附件：SKF授权证书.pdf + 产品规格书.pdf + 报价单.pdf

供应商B操作：
  - 单价：820元/套
  - 总价：410,000元（含税）
  - 交货期：25天
  - 附件：报价单.pdf

预期结果：
  √ 两份报价收到，买家收到通知
  √ 系统自动比价：价差4.88%，供应商B价格更低
  √ AI报价分析：综合考虑交货期，供应商A性价比更高
```

**Step 8：比价分析与谈判**

```
操作：采购员查看比价表
系统展示：
  | 供应商 | 单价 | 总价 | 交货期 | 综合评分 |
  |--------|------|------|--------|---------|
  | 供应商A | 860 | 43万 | 20天  | 92分    |
  | 供应商B | 820 | 41万 | 25天  | 88分    |

采购员向供应商A发起砍价：
  - 目标价：840元/套
  - 理由：竞争对手报价820，请给出最优价

供应商A回复：
  - 最终报价：845元/套，交货期提前至15天

预期结果：
  √ 谈判记录完整保存
  √ 价格变更有迹可查
```

**Step 9：接受报价并生成合同**

```
操作：采购员选择供应商A，点击"接受报价"
预期结果：
  √ 系统自动生成采购合同草稿
  √ 合同内容：双方信息、产品规格、数量、单价845元、总价422,500元、交货条款
  √ 合同编号：CON202403220001
  √ 状态：待签署(PENDING_SIGN)
```

**Step 10：合同电子签署**

```
操作：
  - 采购方（总监）电子签章
  - 供应商（法人/授权人）电子签章

预期结果：
  √ 合同状态：已生效(EFFECTIVE)
  √ 合同PDF生成并存储（含双方签章）
  √ 合同备份至企业档案系统
  √ 供应商收到合同生效通知，进入备货阶段
```

**Step 11：支付与履约追踪**

```
支付：企业对公转账，上传付款凭证
发货：供应商上传物流单号（顺丰：SF1234567890）
收货：采购员在系统确认收货，上传入库单

预期结果：
  √ 订单状态流转：PENDING_PAYMENT→PAID→SHIPPING→DELIVERED→COMPLETED
  √ 每个节点有时间戳记录
  √ 物流轨迹可在系统内查询
```

**Step 12：评价与结算**

```
操作：采购员评价供应商
评价内容：
  - 产品质量：5星
  - 交货准时：5星
  - 服务态度：4星
  - 总评：4.8星，推荐

预期结果：
  √ 评价提交成功
  √ 供应商评分更新
  √ 订单状态：COMPLETED
  √ 企业采购报告自动生成
```

**整体验收标准：**
- 全流程完成时间：≤ 5个工作日
- 所有状态流转正确无误
- 审批记录、操作日志完整
- 合同、发票文件可下载
- 数据一致性：前端显示与数据库记录一致

## 场景二：B2C已定品牌采购

### TC-SCE-010 个人/小微企业采购指定品牌商品

**背景：** 用户需要购买5台联想ThinkPad X1 Carbon笔记本，预算8万元，已明确品牌型号。

**Step 1：搜索产品**
```
输入：搜索"联想 ThinkPad X1 Carbon 2024"
预期：
  √ 搜索结果展示多个供应商的报价
  √ 显示市场参考价区间（15,000-17,000元/台）
  √ 筛选条件：品牌=联想，型号=ThinkPad X1，内存≥16GB
```

**Step 2：比较供应商报价**
```
系统展示：
  | 供应商 | 单价 | 库存 | 交货期 | 评分 | 是否授权 |
  |--------|------|------|--------|------|---------|
  | 数码直供 | 15,800 | 10台 | 3天 | 4.9 | 联想授权 |
  | IT采购站 | 15,500 | 5台  | 5天 | 4.7 | 联想授权 |
  | 极速电商 | 14,900 | 20台 | 2天 | 4.5 | 非授权   |

预期：
  √ 授权供应商标识清晰
  √ AI推荐：综合考虑价格和授权，推荐"数码直供"
  √ 非授权供应商有风险提示
```

**Step 3：直接下单**
```
操作：选择"数码直供"，购买5台
  - 收货信息填写
  - 支付方式：企业网银
  - 发票：增值税普通发票

预期：
  √ 订单创建成功
  √ 无需走采购审批流（金额<10万企业设定阈值）
  √ 供应商收到订单通知，24小时内确认
```

## 场景三：B2C未定品牌采购

### TC-SCE-020 需求驱动型采购（品类导购）

**背景：** 创业公司需要装修办公室，需采购20套办公桌椅，预算4万元，对品牌无要求，希望性价比最高。

**Step 1：描述需求（自然语言）**
```
输入（语音/文字）："我要采购20套办公桌椅，预算4万，上下浮动10%可以接受，
要求桌子有足够的收纳空间，椅子要护腰，希望3周内送到"

AI理解：
  - 品类：办公桌椅套装
  - 数量：20套
  - 预算：3.6万~4.4万（±10%）
  - 功能需求：桌-收纳空间，椅-腰靠支撑
  - 交期要求：≤21天

预期：
  √ 需求解析准确率≥90%
  √ 自动关联品类标签
  √ 展示参考款式和价格区间
```

**Step 2：AI生成采购方案**
```
AI推荐方案：
  方案一（性价比）：
    - 桌：欧意OE-D102，单价680元×20=13,600元
    - 椅：西昊M57，单价980元×20=19,600元
    - 合计：33,200元，节省预算6,800元
    - AI推荐理由：市场口碑好，性价比高，符合功能需求

  方案二（品质）：
    - 桌：好事达Plus系列，单价1,050元×20=21,000元
    - 椅：冈村Contessa，单价1,900元×20=38,000元（超预算）
    - AI提示：超出预算15,000元，不推荐

预期：
  √ 至少3个方案供选择
  √ 方案包含详细清单、效果图参考
  √ 明确标注哪些方案在预算内
```

**Step 3：一键发布需求竞价**
```
操作：用户选择"方案一"，确认后发布竞价需求
预期：
  √ 需求自动发送给平台10家家具供应商
  √ 设定24小时报价截止
  √ 用户收到"已发送给X家供应商，请等待报价"
```

**Step 4：收集报价并AI推荐**
```
收到8家供应商报价（24小时内）：
  - 价格区间：29,800~38,500元
  - AI分析：
    * 最低价29,800（供应商G）：评价一般，交货期30天（超期）
    * 综合最优31,500（供应商C）：高评分，交货18天，质量有保障
    * 推荐：供应商C（31,500元，节省预算8,500元）

预期：
  √ 8份报价均展示
  √ AI推荐报告生成（附理由）
  √ 可按价格/评分/交货期排序
```

**Step 5：确认订单**
```
操作：采纳AI推荐，下单31,500元
预期：
  √ 采购需求完结，整个过程用时约1.5天
  √ 相比自行采购节省：时间节省约60%，价格节省约21%
```

## 场景四：异常与边界场景

### TC-SCE-030 采购需求无匹配供应商

```
场景：采购极冷门商品（某特殊工业原材料），平台无相关供应商
预期：
  √ AI匹配结果：无匹配供应商
  √ 系统提示：建议通过以下方式处理
    - 扩大搜索范围（放宽资质要求）
    - 人工推荐（平台运营介入）
    - 发布公开询价（全网招募）
  √ 用户选择"发布公开询价"，供应商可主动投标
```

### TC-SCE-031 采购中途供应商违约

```
场景：订单已付款，供应商迟迟未发货（超出约定时间3天）
预期：
  √ 系统自动触发超期提醒（供应商+平台运营）
  √ 买家可申请"催货"，供应商强制响应
  √ 超期5天未处理，买家可申请平台介入
  √ 平台介入后：协商赔偿/退款/更换供应商
  √ 违约记录写入供应商信用档案
```

### TC-SCE-032 大促期间高并发采购

```
场景：618大促，系统并发采购请求达到正常流量10倍
预期：
  √ 限流生效（保护核心链路）
  √ 排队机制启动（用户看到"当前排队中"）
  √ 服务不崩溃，降级功能可用
  √ 促销活动数据正确（不超卖）
```
