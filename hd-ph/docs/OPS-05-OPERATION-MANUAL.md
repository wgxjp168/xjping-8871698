## 5.2 公卫医生/护士操作手册

### A. 居民建档

```
【新增居民】
路径: 居民管理 → 新增按钮

必填字段:
  ✦ 姓名（与身份证一致）
  ✦ 身份证号（18位，系统自动校验格式）
  ✦ 性别（男/女）

选填字段:
  □ 出生日期（可从身份证自动解析）
  □ 手机号
  □ 乡镇/村
  □ 详细住址
  □ 民族、血型

注意事项:
  - 身份证号全国唯一，重复会提示已存在
  - 如已存在可直接搜索使用，不要重复建档
  - 地址要精确到自然村（便于下乡分组）

【修改居民信息】
搜索找到居民 → 点击"编辑" → 修改 → 保存
（所有修改有操作日志记录）
```

### B. 体检单管理

```
【创建体检单】
路径1: 居民管理 → 找到居民 → 点击"建体检单"（推荐）
路径2: 体检单管理 → 新建体检单 → 手动填写居民信息

字段说明:
  体检年度: 默认当前年（如2026）
  体检日期: 默认今天
  体检类型:
    1-老年人健康体检（65岁及以上）
    2-高血压患者随访（已确诊）
    3-糖尿病患者随访（已确诊）
    4-孕产妇检查

【体检状态操作】
  待体检(0) → [点击"开始体检"] → 体检中(1)
  体检中(1) → [所有项目完成后"标记完成"] → 已完成(2)
  任意状态  → [点击"作废"] → 已作废(3)（需二次确认）

【查找体检单】
  搜索条件: 姓名/身份证/体检年度/状态
  常用过滤: 今日体检（按checkDate=今天筛选）
```

### C. 体征录入

```
【路径】体检单管理 → 点击体检单"详情" → 左侧"生命体征"面板

【录入规范】
  身高: 精确到0.1cm（如165.5）
  体重: 精确到0.1kg（如62.3）
  收缩压/舒张压: 整数mmHg，测量2次取均值
  脉搏: 整数次/分
  体温: 精确到0.1℃（如36.7）
  腰围: 精确到0.1cm

【BMI自动计算】
  录入身高和体重后，点击"保存体征"
  系统自动计算BMI = 体重(kg) / (身高(m))²
  显示参考标准:
    < 18.5  偏瘦
    18.5~24 正常
    24~28   超重
    > 28    肥胖

【注意事项】
  - 同一体检单体征只有一条记录（重新保存会覆盖）
  - 血压异常（收缩≥140或舒张≥90）系统自动标注⚠️
```

### D. 查阅检验结果

```
【路径】体检单详情 → 右侧"检验结果"面板

【分类标签说明】
  全部     - 显示所有检验项目
  生化     - 肝功、肾功、血糖、血脂等（来自生化仪）
  血常规   - 白细胞、红细胞、血红蛋白等
  尿常规   - 尿蛋白、尿糖、尿潜血等
  糖化Hb   - HbA1c（糖化血红蛋白）

【异常值标识】
  🔴 偏高 (abnormalFlag=1) - 值超出参考范围上限
  🟡 偏低 (abnormalFlag=2) - 值低于参考范围下限
  ⬜ 正常 - 在参考范围内

【如果检验结果未显示】
  可能原因:
  1. 设备尚未完成检测（等待）
  2. ASTM数据未传输（查看设备连接状态）
  3. sampleId与体检单号不匹配（联系检验科核查）
```

## 5.3 DR技师操作手册

### A. 扫码签到（核心操作）

```
【准备工作】
  1. 确认扫码枪/二维码扫描器已连接
  2. 进入 DR管理 → DR扫码签到
  3. 页面加载完成后，输入框自动聚焦（光标在框内）

【操作步骤】
  Step 1: 接收居民纸质DR申请单（上面贴有条码）
  Step 2: 扫码枪对准条码扫描（自动填入输入框）
  Step 3: 扫描后自动回车（或手动按回车键）
  Step 4: 系统显示申请单信息，核对姓名/部位是否正确
  Step 5: 信息无误 → 点击"确认签到"（或签到成功后自动完成）

【签到后操作】
  - 引导居民进入DR室进行检查
  - 检查完成后，回到签到页 → 点击"标记检查完成"
  - 状态变为"已完成"，医生可以出具报告

【常见问题处理】
  条码无法识别:
    → 手动输入条码号 → 回车
  提示"条码不存在":
    → 核查条码号是否正确
    → 联系申请医生确认申请单是否已创建
  提示"已扫码":
    → 说明该居民已完成签到，无需重复操作
    → 若需重新签到，联系管理员重置状态
```

### B. DR报告录入

```
【路径】DR管理 → DR申请单 → 筛选"状态：已完成" → 点击"报告"

【报告内容规范】
  影像所见（客观描述）:
    - 肺野透过度
    - 心影形态大小
    - 纵隔及膈肌
    - 骨骼情况
    示例: "双肺纹理清晰，未见明显渗出及实变阴影。心影不大，
          纵隔不宽。双侧膈肌光整，肋膈角锐利。"

  诊断意见（结论性）:
    - 正常: "胸部X线未见明显异常"
    - 异常: 具体描述（如"右下肺少许纤维灶，建议随访"）

  影像文件上传:
    - 支持格式: jpg/png（< 10MB）或 dcm（< 100MB）
    - 建议上传清晰度≥1024×768的图像

【提交报告】
  点击"提交报告" → 申请单状态变为"已完成"
  等待系统自动上传到公卫平台（每日23:00）
  或手动触发上传（系统管理 → 数据上报）
```

## 5.4 检验科操作手册

### A. 设备状态确认

```
每日开机后检查:
1. 打开系统 → 设备管理 → 查看设备列表
2. 确认所有设备状态为"在线"（绿色状态点）
3. 若设备"离线":
   a. 检查设备是否开机
   b. 检查网络连接（ping 设备IP）
   c. 检查设备软件是否在上传/推送模式
   d. 重启设备软件后等待重连
```

### B. 日常标本处理

```
【接收标本】
1. 核对标本条码与转运清单（数量/编号）
2. 检查标本质量（溶血/脂血/量不足标注）
3. 在系统中标记"已接收"（体检单状态: 0→1）

【上机检测】
1. 根据标本类型分配到对应设备
   血清管 → 生化仪（BS-230 或 cobas c311）
   EDTA管 → 血常规仪（BC-5390 或 XE-2100）
   尿杯   → 尿分析仪（BU-680 或 CV-600）
   EDTA管 → 糖化血红蛋白仪（HA-8180，另取5μL）

2. 在设备中输入样本ID（与体检单号一致）
   ⚠️ 重要: 设备中的样本ID必须与系统体检单号完全一致
           否则系统无法自动匹配结果

3. 设备完成检测后自动推送ASTM数据（无需手工操作）

【结果核查】
设备上传完成后（约2-3分钟），系统中查看:
→ 设备管理 → 待处理数据 (processStatus=0的记录)
→ 若有待处理记录，系统后台任务5分钟内自动处理
→ 体检详情页刷新查看结果
```

## 5.5 系统管理员操作手册

### A. 日常运维检查（每日8:30）

```bash
# 登录服务器后执行以下检查
cd /opt/hd-ph

# 1. 检查所有容器状态
docker-compose ps
# 期望: 所有服务 Status=Up

# 2. 检查今日错误日志
grep "ERROR\|Exception\|WARN" logs/*/$(date +%Y-%m-%d)*.log 2>/dev/null | head -50

# 3. 检查数据库
docker exec hd-mysql mysql -uroot -p"${MYSQL_ROOT_PASSWORD}" \
  -e "SHOW PROCESSLIST; SELECT COUNT(*) as today_orders
  FROM hd_public_health.check_order WHERE DATE(create_time)=CURDATE();"

# 4. 检查Redis
docker exec hd-redis redis-cli INFO memory | grep used_memory_human

# 5. 检查磁盘（DR影像可能占用较大）
df -h /opt/hd-ph/data
```

### B. 账号管理

```
【新建账号】
系统管理 → 用户管理 → 新增用户
  用户名: 建议使用 机构缩写+姓名拼音（如 mzsy_zhangsan）
  初始密码: hd2024（用户首次登录后必须修改）
  用户类型: 1=普通用户 2=医生 3=管理员
  所属机构: 选择对应卫生院/机构
  分配角色: 根据岗位选择（见权限体系文档）

【禁用/删除账号】
离职人员: 用户管理 → 找到用户 → 点击"禁用"（不要直接删除，保留操作记录）

【密码重置】
用户管理 → 找到用户 → 点击"重置密码" → 确认
重置后密码为: hd2024（通知用户立即修改）
```

## 5.6 公卫科长/统计人员操作手册

### A. 数据统计查看

```
【体检完成率统计】
路径: 首页概览 → 查看"本年体检人次"
     或: 体检单管理 → 按年度/机构/类型筛选 → 查看列表数量

【异常指标分析】
路径: 体检单详情 → 检验结果 → 点击"导出"
     → 生成Excel，包含所有异常标记项目

【DR数据统计】
路径: DR申请单列表 → 按状态筛选"已上传"
     → 核对上传数量与DR拍摄数量是否一致
```

### B. 数据导出

```
支持导出格式: Excel (.xlsx)
导出内容:
  □ 居民档案列表
  □ 体检单列表（含状态）
  □ 检验结果汇总（按类别）
  □ DR申请/完成情况

操作: 相应列表页 → 点击"导出"按钮
     → 选择导出范围（当前页/全部）
     → 下载Excel文件
```
