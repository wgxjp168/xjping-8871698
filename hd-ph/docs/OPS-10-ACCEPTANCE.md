# 10 · 项目验收标准与试运行考核指标

## 10.1 验收总体原则

```
验收原则:
  ① 功能完整性: 所有合同约定功能均已实现并可正常使用
  ② 性能达标:   关键接口响应时间符合SLA要求
  ③ 安全合规:   通过安全测试，无高危/中危漏洞
  ④ 数据准确:   设备采集数据与人工核对一致率 ≥ 99.9%
  ⑤ 业务可用:   完整业务流程无阻断性问题
  ⑥ 文档齐全:   操作手册、运维文档、培训材料完整

验收组成员（建议）:
  - 县卫健局信息科长（验收组长）
  - 县公卫科业务负责人
  - 各卫生院信息员代表（3人）
  - 检验科/DR室代表（2人）
  - 系统开发方项目经理
  - 第三方测评机构代表（可选）
```

## 10.4 安全验收标准

```
必须0高危漏洞才能通过验收:

高危 (必须修复才能上线):
□ SQL注入漏洞
□ 未授权访问（无需登录访问任意接口）
□ 水平越权（A用户可访问B用户数据）
□ 垂直越权（低权限用户执行高权限操作）
□ 敏感信息泄露（密码/密钥明文传输或返回）

中危 (上线前修复，可带观察期):
□ XSS跨站脚本
□ 弱密码策略（无密码复杂度要求）
□ 会话固定

低危 (3个月内修复):
□ 信息枚举（错误信息过于详细）
□ 安全响应头缺失
```
