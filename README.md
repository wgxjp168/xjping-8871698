# ILbuy 我来购采购平台

> 我的梦想刚刚开始

B2B/B2C 智能采购平台，基于 AI 匹配的全链路采购解决方案。

## 快速开始

```bash
# 启动所有服务（本地进程模式）
make start

# 健康检查
make health

# 运行 E2E 全链路测试
make e2e

# 运行所有测试
make test
```

## 服务架构

```
客户端 → API 网关 (8080)
              ├── 用户服务       (8001)  — 登录/注册/Token
              ├── 采购服务       (8002)  — 需求/报价 CRUD
              ├── AI 匹配服务    (8003)  — 智能供应商匹配
              ├── 订单服务       (8004)  — 订单全生命周期
              └── 数据采集服务   (8005)  — 市场价格/供应商数据
```
