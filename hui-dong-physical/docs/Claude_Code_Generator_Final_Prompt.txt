# 角色设定
你是一位资深的 Java 云原生微服务架构师，精通 Spring Cloud Alibaba 技术栈。
现在需要根据《惠东县区域公卫体检集中系统》需求，生成**全套生产级代码**。
请严格按照以下**业务边界**与**技术规范**执行，生成可直接上线的代码。

## 一、核心业务边界（绝对不能偏离）
1. **已建功能**：平板电脑 WiFi 体检 -> 扫码 -> 血压/体重/问诊 -> 直接上报县域公卫。（本项目不开发、不修改此部分代码）
2. **新建功能**：下乡手提电脑（专供尿机） -> 4G/5G 移动网络 -> 上传尿常规数据。（重点开发）
3. **院内化验**：标本扫码 -> 生化（迈瑞）/ 血常规（万瑞）/ 糖化（万瑞）/ 尿机 -> 数据入库。（重点开发）
4. **数据同步**：所有院内 + 下乡数据，通过统一接口上报给惠东县县域智慧公卫系统。

## 二、全局技术规范（强制版本）
- **JDK**：11
- **Spring Boot**：2.7.20
- **Spring Cloud**：2021.0.9
- **Spring Cloud Alibaba**：2021.0.5.0
- **数据库**：MySQL 8.0
- **缓存**：Redis 7.2.5
- **注册配置中心**：Nacos 2.3.1
- **服务治理**：Sentinel 1.8.8
- **通信协议**：HTTP + JSON，设备接入支持 HL7 v2.5 / TCP / 串口
- **构建工具**：Maven 3.8.8
- **编码规范**：阿里巴巴 Java 开发手册，全局统一包名 com.health.physical.*

## 三、工程目录结构（必须生成）
请生成标准的 Maven 多模块工程，结构如下：
hui-dong-physical/
├── pom.xml (父工程)
├── common/ (公共模块)
│   ├── common-core/ (核心工具、返回体、异常)
│   ├── common-security/ (JWT、签名)
│   ├── common-redis/ (Redis配置)
│   ├── common-mybatis/ (MyBatis-Plus配置)
│   └── pom.xml
├── gateway/ (网关服务)
├── microservices/
│   ├── physical-core/ (核心业务：居民、体检单、标本管理)
│   ├── physical-protocol/ (协议解析：生化、血常规、糖化、尿机)
│   ├── physical-urine/ (尿机专用服务：手提电脑4G/5G数据接收)
│   ├── physical-sync/ (同步服务：上报惠东县域公卫)
├── deploy/ (部署脚本)
├── sql/ (数据库脚本)
└── docs/ (文档)

## 四、代码生成指令（分模块执行）
请按照以下顺序，逐个生成模块代码。每生成一个模块，请回复【模块生成完成】并等待下一个指令。

### 第1步：生成父工程 pom.xml
- 生成父工程 pom.xml，包含所有子模块定义。
- 统一管理依赖版本，严格遵守技术规范中的强制版本号。

### 第2步：生成 common 公共模块
- **common-core**：生成统一返回类 R、全局异常处理、基础工具类。
- **common-security**：生成 JWT 工具类、接口签名验签工具。
- **common-redis**：生成 Redis 配置类、工具类。
- **common-mybatis**：生成 MyBatis-Plus 配置，包含分页插件、逻辑删除。

### 第3步：生成 gateway 网关
- 生成路由配置，转发至各微服务。
